# 이번 재구현 범위

> 초기 v1 재구현의 계약·범위·결과 기록이다. 현재 alpha.5의 추가 범위와 공개 절차는 [구현 상태](status.md), [Summary와 기획 완료](summaries.md)를 우선한다.


Handrail을 새로운 컴포넌트 구조로 재구현한다. 기준은 2026년 10월 6일 재구현 요청과 같은 날 논의한 조율·권한·worktree·HERDR_ENV 개선이다. 과거 backlog 문서는 이 구현의 요구사항이 아니다.

## 포함

후속 승인된 alpha.2 범위는 [체크리스트](checklist-v1-host-test.md)의 CHK-001~004와 [설정 절차](onboarding.md)다. 설치 경로 발견, 최소 입력 설정, 부모 Review 열 및 계획별 하위 프로젝트 준비를 포함한다.

- 설치 진단, 비밀 입력을 사용하는 연결 설정, 저장소와 기존 보드 바인딩.
- 계획과 작업 카드, 기준별 증거, 검수·통합·검증·사용자 수락, 추가 전용 이력.
- Herdr room과 작업자 실행, 명시적 모델 배정, 지시 전달·관찰·복구.
- Vikunja v2 카드·관계·상태·댓글 연동 어댑터와 명시적 동기화.
- 실제 자원 경로 사전 점검, 회차별 승인 재사용, 변경된 권한 범위 출력.
- 외부 영속 worktree, 실행 중 경로 고정, Review 보존, 승인된 정리.
- 구조화 오류, 불확실한 전송의 재조정, 내부 후처리 훅.
- 소스/플러그인 배포 구성, 아키텍처·철학·운영·에이전트 스킬 문서.

## 경계

Vikunja와 Herdr는 외부 제품이다. 이 저장소에는 그 서버나 UI를 구현하지 않는다. 기존 서비스의 설치·업그레이드·운영 및 테스트 프로젝트 수정도 포함하지 않는다.

v0.5의 직접 worker subprocess 실행 경로와 Herdr 실행 경로를 함께 유지하지 않는다. 신규 공개 명령과 상태 형식은 v1 계약을 따른다. v0.5 상태 자동 마이그레이션, 과거 계획의 자동 이관, 원격 Git push/PR, 모델 자동 선택, 임의 shell hook은 이번 범위에 없다. 계획별 하위 프로젝트 생성은 후속 alpha.2 요청으로 포함했다.

기존 미커밋 분석 문서는 `docs/reviews/`에 보존한다. 교체된 안내 문서 원본은 `docs/archive/pre-rebuild/`에 있다. 이들은 참고 기록이며 구현 backlog가 아니다.

과거 런타임과 그 API에 종속된 테스트는 새 실행 트리에서 제거했다. 원본은 `support-herder` 브랜치 이력에 남는다. 기존 개발 명세와 버전별 안내는 보관 영역으로 이동했다. 새로운 회귀 테스트 작성·실행은 이번 구현 요청과 별도로 진행할 검증 단계다.

## 브랜치와 이력

초기 구현은 `rebuild/handrail-agentroom-v1`에서 진행하며 과거 메인과 브랜치를 보존했다. 이후 **2026-10-08 사용자의 명시적 초기화 요청**에 따라 현재 코드·문서를 새 `main`의 최초 커밋으로 전환하고 이전 로컬 Git 이력·브랜치를 제거했다. 이 문서의 `support-herder` 등 과거 브랜치 언급은 당시 이력 설명이며 현재 조회 가능한 브랜치를 뜻하지 않는다. 원격 이력 변경이나 강제 push는 수행하지 않았다.
