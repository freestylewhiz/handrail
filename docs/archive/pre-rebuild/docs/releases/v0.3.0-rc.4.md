# Handrail 0.3.0-rc.4

**Traceable development workflows for humans and coding agents.**

*Keep human-agent development on track.*

## What's included

- One parent project per repository, with explicitly registered child boards.
- Plan and work cards linked through actual Vikunja subtask relations across boards.
- Reviewed, integrated and verified work becomes Done; the complete plan moves to Review for the user.
- Explicit user acceptance for plan Done; review feedback creates new work cards and preserves earlier history.
- Human card changes can be previewed, adopted or reconciled without inventing verification evidence.
- Durable operation tracking for interrupted updates, duplicate prevention, and stale-evidence checks.
- Worker execution authorization previews and `confirm` / `workspace-auto` profiles for Codex and Cursor workers.
- Offline Korean `help workflow`, `help terms`, and `help sync` for the orchestrator.
- Updated project introduction, philosophy, workflow diagram and terminology.

## Install or update

```sh
codex plugin marketplace add freestylewhiz/handrail --ref plugin-v0.3.0-rc.4
codex plugin add handrail@handrail
codex plugin list --marketplace handrail
```

When upgrading an already registered Handrail marketplace, run `codex plugin marketplace remove handrail` before the commands above to switch its pinned source. This preserves Handrail connection profiles and Vikunja data.

Start a **new Codex session** in your new project's Git repository. Ask the orchestrator to show Handrail's workflow and connect the repository to its own Vikunja parent project. Existing connection profiles can be reused; each repository has its own binding.

The plugin tag includes the built Python runtime. The source tag is `v0.3.0-rc.4`; cloning the development source is not required for installation.

## Verification and current scope

- Real Vikunja acceptance uses an isolated test instance and a deterministic worker CLI, with actual Git integration and supervisor execution.
- Regression coverage includes the provider execution/authorization contract, packaging, isolated launcher, card workflow and recovery paths.
- Exact test counts, source/distribution revisions, ZIP checksum, remote installation and downloaded asset checks are recorded in `handrail-release-evidence.json`.
- Linux, Python 3.9+ and Git are required. Vikunja and authenticated worker CLIs are operated separately.
- This is a prerelease. Codex is the orchestrator; Codex and Cursor are worker options. Runs are sequential per repository. Child-project creation, Cursor orchestration and remote Git operations are outside this candidate's workflow.
